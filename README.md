A simple Flask-based Unit Converter web application that converts between different units of length, weight, and temperature. Users can enter a value, choose the unit to convert from and to, and view the converted result on the same page.

The project includes conversions for:

- Length: millimeter, centimeter, meter, kilometer, inch, foot, yard, and mile
- Weight: milligram, gram, kilogram, ounce, and pound
- Temperature: Celsius, Fahrenheit, and Kelvin

Built using Python, Flask, HTML, CSS, Jinja templates, and Bootstrap.
